02 · A FERRAMENTA

Pouca estrutura para começar

Sinatra é uma DSL para criar aplicações web em Ruby: uma linguagem de domínio específico expressa no próprio Ruby.

Sua interface aproxima o código da requisição HTTP: escolher uma rota e executar um bloco.

Rotas, filtros e templates formam a base da ferramenta.03 / 17
03 · RUBY + SINATRA

Uma rota é código Ruby

get '/ola' do
  'Olá, Sinatra!'
end

get

Método oferecido pelo Sinatra para registrar uma rota.

do … end

Bloco Ruby executado quando a rota é atendida.

Última expressão

Aqui, a string se torna o corpo da resposta.

Exemplo didático independente do projeto.04 / 17
04 · PRIMEIROS PASSOS

Do arquivo ao navegador

gem install sinatra rackup puma

06 · ROTAS

Método + caminho → ação

get '/artigos' do
  'Lista de artigos'
end

post '/artigos' do
  status 201
  'Artigo criado'
end

A mesma URL pode ter comportamentos diferentes conforme o método HTTP.

O Sinatra também oferece put, patch e delete.

Exemplo didático: nenhuma gravação no banco é realizada aqui.07 / 17
07 · ENTRADA

Como os dados chegam

get '/artigos/:id' do
  id = params['id']
  filtro = params['busca']
  "Artigo #{id}; busca: #{filtro}"
end

Na URL

/artigos/42?busca=ruby → id: "42", busca: "ruby".

No corpo JSON

No projeto: JSON.parse(request.body.read).

Na aplicação

Validar e converter os valores recebidos.

O corpo JSON é lido explicitamente; não vira params automaticamente.08 / 17
08 · SAÍDA

Controle da resposta HTTP

require 'json'

get '/saude' do
  content_type :json
  status 200
  { status: 'ok' }.to_json
end

content_type

Define o tipo do conteúdo enviado.

status

Define o código HTTP da resposta.

to_json

Serializa os dados com a biblioteca JSON do Ruby.

09 / 17
09 · REUTILIZAÇÃO

Filtros e helpers

before do
  content_type :json
end

helpers do
  def invalid_input(message)
    halt 400, { error: message }.to_json
  end
end

before

Executa lógica antes das rotas. No projeto, define JSON como padrão.

helpers

Agrupa métodos usados nos blocos das rotas.

halt

Interrompe o fluxo e devolve uma resposta.

Trecho real de app.rb; a biblioteca JSON é carregada no início do arquivo.10 / 17

13 · CÓDIGO DO PROJETO

Uma rota real, passo a passo

post '/tasks' do
  attributes = json_attributes(['title'])
  task = create_task(attributes['title'])
  status 201
  task.to_json
end

1 · Receber e validar

json_attributes é um helper criado no projeto.

2 · Persistir

create_task usa SQLite; não é um recurso nativo do Sinatra.

3 · Responder

Sinatra define o status; Ruby serializa a tarefa.

Trecho real de app.rb. A regra da aplicação fica dentro do fluxo da rota.14 / 17

15 · CONCLUSÃO

Da requisição ao bloco Ruby

Sinatra oferece uma forma direta de definir o comportamento de uma aplicação web.

Rotas conectam HTTP ao código. Filtros, helpers e templates ajudam a construir a aplicação.

A API de tarefas é um exemplo de como combinar esses recursos.16 / 17
